# Legacy dotfiles

The v1 repository baked personal configuration into `/etc/skel`.

The v2 image intentionally does not do that.

Keep your live workstation dotfiles in a dedicated repository (recommended)
or copy the old files from the v1 git history if you need them for reference.

Do not copy large prebuilt binaries such as `hyprtabs` or `trash` into this
directory. Package/install them separately.
